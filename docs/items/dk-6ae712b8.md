# FullStateReport: named validated fields instead of positional list

Push review (abstraction): LegacyMessages.kt:30 stores fields as List<Int> read by index; decode repeats the order in separate range checks; wirePayload() re-serialises. Direction: decode into named validated fields in one constructor and derive wirePayload() from them (keep raw bytes only if the ack must echo exactly). Also removes the encoder's dependence on wirePayload (componentization P2).

Resolution (2026-10-28, android-ble-live-state, folded into dk-d19640b7): FullStateReport is a data class of nine named wire fields, range-checked in one isValid(); wirePayload() derives the nine bytes from them (each field is one wire byte, so the ack echo stays exact; LegacyFrameDecoderTest ack vector unchanged). The encoder still calls wirePayload() for the 0x48 ack: the ack must carry the report payload, so that dependence was kept deliberately.
