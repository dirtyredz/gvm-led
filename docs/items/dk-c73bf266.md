# Unify the light-catalog and wanted-state store contracts and initialisation


Baseline review 2026-10-31 (abstraction lens, sign-off). Extends dk-5487c6a4 (the import cycle).

Facts: LightCatalogStore returns StoredCatalog (legacy v1 keys) and the repository does codec/migration; WantedStateStore passes raw text with the codec in LightControlRepository. LightControlRepository decodes in its constructor on the main thread (built in AppContainer); LightCatalogRepository loads async on io behind an initialized gate.

Direction: one contract for both stores (ports speak domain values; preferences adapters own codec and migration), one initialisation pattern (async on io with an init gate), or record in ARCHITECTURE why control state must be synchronous.
